# Sky Agri Command

Sky Agri Command is a smart agriculture drone management platform designed to monitor and manage agricultural drone operations.

## Features

- Drone monitoring dashboard
- GPS tracking
- Mission planning
- Flight status monitoring
- Simulation mode
- Future Pixhawk and ESP32 integration

## Technologies

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase

## Simulation Mode

The project currently uses simulation mode to test drone monitoring and control features without physical hardware.

## Hardware Integration

Future versions will support Pixhawk, ESP32, GPS, and other drone hardware.

The dashboard and simulation features are currently implemented. Real hardware integration is planned for future development.
